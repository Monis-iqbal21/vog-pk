## Verification scope and limits

Rows were editorially selected from public retailer category pages, without bulk scraping, filter/search endpoints, automated catalogue extraction, or downloads of retailer media. The public robots.txt was checked first; its disallowed filter, account, cart, and API routes were not used. Browser retrieval returned some cached and legacy pages, and some product-detail requests failed; checkedAt records the actual retrieval date, not a guarantee that the price was refreshed that day. Prices must be reconfirmed. Category-page reference values were observed; no supplier stock count or VOGPK stock status was inferred.

Descriptions are original, limited to the basic features present in the retrieved sources. Manufacturer references were consulted for selected models. A family page or an unavailable detail page is not a complete exact-SKU verification: per-record specificationVerification makes remaining checks explicit. The catalogue is therefore NOT fully launch-verified. Retailer brand/category inconsistencies were excluded or corrected using identifiable models; laptop memory, used/open-box products, and color-only duplicates were avoided. Capacity-distinct SSD and memory products remain separate genuine variants.

The supplied brief overrides the previous seven-product limit: Featured and New Arrivals now have eight products plus See All; every category has seven real products plus See All. The compact-row behavior for small collections remains available.
