## Counts and scope

- Total unique products: 84.
- Total unique real photographic candidates downloaded: 7; 4 selected and integrated, 3 rejected or pending. One additional downloaded image is a benchmark chart, not a product photograph.

A result is not a permission grant, verified exact variant, or download. Batch candidate pages can relate to any query in that batch. Reference links in the table identify intended hardware; they do not identify a licensed photograph. Competitor-owned photography was not copied.

[File manifest](product-image-files.json) includes original download URLs, source/output sizes, actual encoding, byte counts and SHA-256 hashes. The source filename for the Ultra 9 photo mentions a video about Ultra 7; the pictured chip visibly reads 285K and Commons categorizes it as 285K. It must not be assigned to 265K. The i9's 600 px source is retained without artificial upscaling. Other source frames are contained inside transparent 1000 px square canvases; no product edges are cropped and source backgrounds remain intact.

Run `node scripts/prepare-product-images.mjs` from frontend to prepare the reviewed allowlist. It stops on HTTP errors rather than bypassing access controls. A repeat request for the already downloaded 285K source returned HTTP 429; no rate-limit retry was made. Final preparation used existing local originals via `--source-dir <cache-directory>` (files named `<product-id>.source`). The exact-model and permission review must precede additions to this allowlist.
